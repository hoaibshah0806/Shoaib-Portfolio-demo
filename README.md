# Shoaib-Portfolio-demo

> **"ARISE."** — A high-performance, single-page developer portfolio for **Mohammed Shoaib Shah** built with a **Solo Leveling System UI** anime aesthetic blended with modern high-velocity tech visuals.

- **Player**: Mohammed Shoaib Shah

- **Class**: Shadow Backend Monarch
- **Agility Stats**: District-Level Athlete (100m & 200m Sprint Engine)

## 🎮 Features & System Architecture

1. **The Awakening (Hero Section)**
   - 3D Interactive Shadow Blade (*Kamish's Wrath / Kasaka's Venom Fang*) with mouse-tilt parallax, rotating system runes, and expanding shadow aura on hover.
   - Dual-view toggle supporting both Canvas 3D and Spline 3D Viewer (`@splinetool/viewer`).
   - Animated typewriter system alert notice: `[System Notice: Player Mohammed Shoaib Shah has logged in.]`.

2. **Player Stats (Status Window - About Me)**
   - Holographic blue translucent status window modeled after Solo Leveling.
   - Live telemetry gauges: HP (Stamina), MP (Kafka Event Stream Mana), and Fatigue.
   - Full attribute matrix: Strength (88), Agility (99 MAX - District Sprinter), Intelligence (96), Vitality (92), Sense (90).

3. **Inventory & Skills (Bento Box Grid)**
   - Interactive glassmorphic cards with cursor-following particle spotlight, electric blue hover illumination, and 110% Lucide icon zoom.
   - Categorized by Hunter Ranks: S-Rank (Spring Boot, Go, Kafka, Architecture), A-Rank (DevOps, AI/ML).

4. **Quest Log (Projects Timeline)**
   - GSAP ScrollTrigger alternating slide-in reveal animations.
   - S-Rank Quests: Distributed Event-Driven Pipeline, High-Throughput Microservices Engine.
   - A-Rank Quests: Low-Latency Go Micro-Broker, Intelligent Cloud Ops & ML Pipeline.
   - Interactive `[ACCEPT QUEST]` system awarding XP with audio fanfare and notification toasts.

5. **Guild Terminal (CLI Gateway / Contact)**
   - Built-in interactive command-line interface.
   - Commands: `contact --email`, `contact --socials`, `stats`, `quests`, `athlete`, `help`, `clear`, and secret `sudo awaken`.

6. **Web Audio API Synthesizer**
   - Synthesized Solo Leveling UI ping alerts, sub-bass awakening rumble, and level-up chimes (pure Web Audio API, zero audio asset downloads needed).

## 🚀 Quick Start

Simply open `index.html` in your browser:

```bash
# Or run with Python local server
python -m http.server 5173
```

Visit `http://localhost:5173` in your browser.
